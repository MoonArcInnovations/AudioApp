2. What Audiologists See and Determine

The Complete Audiological Test Battery

Audiological Test Battery Flow

Pure Tone Audiometry (PTA)

  • Air Conduction (AC) - Entire auditory pathway
  • Bone Conduction (BC) - Inner ear only
  • Frequencies: 250-8000 Hz
↓

Speech Audiometry

  • Speech Reception Threshold (SRT)
  • Word Recognition Score (WRS)
  • Speech Discrimination Score (SDS)
↓

Immittance Audiometry

  • Tympanometry - Middle ear function
  • Acoustic Reflexes - Stapedius response
↓

Objective Tests

  • OAE (Otoacoustic Emissions) - Cochlear function
  • ABR (Auditory Brainstem Response) - Neural pathway

Output Description Values

PTA Pure Tone Average dB HL value per ear

Clinical Flags Warnings Asymmetry, NIHL pattern, etc.

3. Air Conduction vs Bone Conduction

The Critical Relationship

Test Measures Pathway Equipment
Air Conduction (AC) Complete auditory system Outer → Middle → Inner ear → Nerve Headphones
Bone Conduction (BC) Inner ear only Skull → Inner ear → Nerve Bone vibrator

Types of Hearing Loss

✅

Normal Hearing

AC = BC ≤ 25 dB
No gap, both normal

🔶

Conductive

AC > BC by 15+ dB
BC normal, AC elevated

🔴

Sensorineural

AC = BC > 25 dB
Both elevated, no gap

🟣

Mixed

AC > BC, both elevated
Gap + BC shift

Recommended Approach: Numerical Data Pipeline

AI Audiometry Pipeline Architecture
1

Input: 28 Threshold Values

Air Conduction: 8 frequencies × 2 ears = 16 values
Bone Conduction: 6 frequencies × 2 ears = 12 values

2

Feature Engineering

PTA calculation, Air-Bone Gap per frequency, Slope calculation, Notch detection

3

Dual Processing

ML Model (TFLite/ONNX) for predictions + Rule Engine for validation and safety checks

4

Ensemble Fusion

Combine ML predictions with rule-based validation. Override ML if red flags detected.

5

Output: Complete Assessment

Type (Normal/Conductive/SNHL/Mixed), Degree, Configuration, and Recommendations

Two Approaches Compared

Image-Based (CNN)
  • ✅ Works with existing audiogram images
  • ✅ High accuracy (97.5%)
  • ✅ Can process varied visual formats
  • ❌ Requires image preprocessing
  • ❌ Sensitive to visual variations
  • ❌ More computationally intensive
✓ Numerical Data (Recommended)
  • ✅ Faster inference
  • ✅ More interpretable
  • ✅ Works directly with app data
  • ✅ Easier to add rules/heuristics
  • ❌ Requires clean numerical input
  • ❌ May miss some visual patterns

What AI Can and Cannot Do

✅ AI CAN Do
  • Classify hearing loss type
  • Calculate degree of hearing loss
  • Identify audiogram patterns
  • Detect NIHL notch patterns
  • Flag asymmetric hearing loss
  • Generate educational reports
  • Recommend professional referral
❌ AI CANNOT Do
  • Physical examination (otoscopy)
  • Tympanometry testing
  • OAE/ABR testing
  • Complex case counseling
  • Definitive medical diagnosis
  • Legal liability for diagnosis
  • Specific treatment recommendations
